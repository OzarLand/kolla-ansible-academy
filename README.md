# Kolla-Ansible Academy has moved

Kolla-Ansible Academy is now the module **Operate** of **OzarLand Academy**, the learning path of
[OzarLand](https://github.com/OzarLand/ozarland):

- **Read it:** <https://academy.ozarland.com/day2/>
- **Sources, with their whole history:** [OzarLand/ozarland-academy](https://github.com/OzarLand/ozarland-academy),
  under [`docs/day2/`](https://github.com/OzarLand/ozarland-academy/tree/main/docs/day2)
- **Issues and contributions:** [OzarLand/ozarland-academy](https://github.com/OzarLand/ozarland-academy/issues)

This repository is archived. Its former site, `https://ozarland.github.io/kolla-ansible-academy/`, now redirects every
page to the same page of the portal: [`redirect/`](redirect/) holds the redirections, written by
[`tools/site/redirect_site.py`](https://github.com/OzarLand/ozarland-academy/blob/main/tools/site/redirect_site.py)
of ozarland-academy, and [`.github/workflows/pages.yml`](.github/workflows/pages.yml) publishes them.

Its history up to the move is kept here and in ozarland-academy.
